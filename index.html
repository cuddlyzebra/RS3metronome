RS3 TICK METRONOME

600ms-accurate tick timer with sync
Step 1: Point at a spot that's updating
Open your RuneMetrics tab in-game (F7, if that's not bound to anything else) with "Show precise values" and "Show XP change value" turned on, so its numbers are actually changing. Then hover over a section that's actively updating -- usually the XP/hr column for whatever skill you're training. RuneMetrics only ever updates on a game tick, so any changing number there works as a sync point; it doesn't matter which one.
